# VoltBeam · sitio y plantillas demo

Páginas web de alta conversión y asistentes de IA en WhatsApp para negocios de León, Gto.

- **Sitio:** https://abebm7-lab.github.io/voltbeam-demos/
- **Demo consultorio dental:** https://abebm7-lab.github.io/voltbeam-demos/demos/consultorio-dental/
- **Demo restaurante:** https://abebm7-lab.github.io/voltbeam-demos/demos/restaurante/
- **Demo taller mecánico:** https://abebm7-lab.github.io/voltbeam-demos/demos/taller-mecanico/

Sin build: HTML + Tailwind CDN + Lucide + JavaScript puro, publicado con GitHub Pages.
Todo el contenido se edita en `config.js`. Instrucciones en [GUIA-EDICION.md](./GUIA-EDICION.md).
